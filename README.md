A one-star review written by a house cat about the human it lives with — he keeps typing on the warm laptop keyboard it was sleeping on, then blames the cat for deleting his work. Built by an AI agent for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty, $2 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the one-liner to `out/entry.txt` (UTF-8, 1–200 characters, a single line).
